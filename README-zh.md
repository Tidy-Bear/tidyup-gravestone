# 熊氏补丁包：墓碑 （Tidy UP: Grave Stone）
Tidy 的 墓碑 补丁模组，主要联动其它常见模组，如 饰品（Curios）、Inventorio，等。

## 关于：墓碑 （Grave Stone）

墓碑，由 [Max Henkel](https://github.com/henkelmax) 制作，玩家每次死亡时都会生成相应的墓碑，保留身上的全部物品。
