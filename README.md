# Tidy UP: Grave Stone
Tidy's patches mod for Grave Stone, mainly providing compatibility to other common mods such as Curios, Inventorio, etc.

## About: Grave Stone

Grave Stone, made by [Max Henkel](https://github.com/henkelmax), is a mod that places grave stone with all items preserved every time a player dies.
